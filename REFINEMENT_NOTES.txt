THE MUSEUM OF US — REFINEMENT NOTES
====================================

What changed
------------
- Split curator-only dashboard and memory-editor rules into css/admin.css.
- Kept shared foundations and sign-in/shared protected-page styles in css/style.css.
- Kept museum welcome, gallery, collection, card, and overlay styling in css/museum.css.
- Added the admin stylesheet to admin.html and aligned its font loading with the other pages.
- Removed the outdated sign-in-page message that said secure sign-in was still planned.
- Replaced placeholder "planned" admin cards with descriptions of existing features.
- Added explicit, stable form layout classes instead of relying on nth-child positions.
- Improved the featured-memory grid so only explicitly featured memories receive the wide layout.
- Made photo visibility follow post_type rather than collection, so collections and post types remain independent.
- Added post-type labels and distinct detail-view styling for letters, milestones, and notes.
- Fixed the admin memory query so editing a memory retains its saved post_type.
- Added post-type and featured information to the curator's saved-memory list.
- Updated documentation with structure, required database fields, and manual test steps.

What was intentionally not changed
----------------------------------
- No database migrations or Supabase policies were changed.
- No authentication model, role rules, or private Storage permissions were changed.
- No service-role key or database password was added to browser code.
- Existing assets and the Supabase project configuration were preserved.

Validation performed
-------------------
- All JavaScript files passed Node.js syntax checks.
- All three CSS files parsed without CSS syntax errors.
- All HTML pages parsed; no duplicate IDs or missing label targets were found.
- All local script and stylesheet references in the HTML pages point to files in this package.

Limitations
-----------
- An authenticated end-to-end test against the live Supabase project was not possible here.
- Browser-level visual testing could not be completed in this environment.
- Follow the manual test checklist in README.txt before publishing the refined build.
